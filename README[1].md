# Bhavna Yadav — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu and dynamic year

## Run locally
Open `index.html` in your browser.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. Your portfolio will get a GitHub Pages URL.

## Before publishing
Replace any project/repository links with the exact live URLs you want to show.
Add an email/contact button if you want recruiters to contact you directly.
